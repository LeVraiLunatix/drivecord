# Contribuer à Drivecord

Merci de vouloir aider ! La suite Cord est un projet perso de **Lunatix**, ouvert aux contributions.

## Avant de commencer

- Pour un bug ou une idée, ouvre d'abord une *issue* ou passe sur le [Discord de la suite](https://discord.gg/EyX2YR6nAy) : on en parle avant que tu passes du temps dessus.
- Garde les changements ciblés : une *pull request* = un sujet.
- Les textes de l'interface sont en français, sur un ton simple et tutoyé.

## Signer tes commits (DCO)

Chaque commit doit être signé avec le [Developer Certificate of Origin](https://developercertificate.org/) : tu certifies que tu as le droit de proposer ce code et que tu acceptes qu'il soit distribué sous la licence du projet (AGPL-3.0-or-later).

C'est une simple ligne, ajoutée par Git avec l'option `-s` :

```
git commit -s -m "Corrige l'affichage des dates"
```

qui ajoute à la fin du message :

```
Signed-off-by: Ton Nom <toi@exemple.fr>
```

Les *pull requests* dont les commits ne sont pas signés ne pourront pas être fusionnées.

## Ce que tu acceptes

En contribuant, tu acceptes que ta contribution soit publiée sous AGPL-3.0-or-later dans Drivecord. Les noms et logos de la suite restent à Lunatix (voir [NOTICE.md](NOTICE.md)).
